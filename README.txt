MATLAB code for "Emergent viscoelasticity of biological materials with turnover" by M. D. Butler, T. Shearer, M. G. Hennessy, G. Charras and P. Pearce

------
Figures: Contains data and code to generate figures in the main text.
Run each .m file to generate the appropriate subfigure.

------
Simulation: Contains example code used to evolve the ODE system being studied.
RunSpringsModel.m runs an example constant strain test.
EvolveSpringsModel.m numerically integrates the ODE for abundant material.
EvolveSpringsModel_FiniteBath.m numerically integrates the ODE for finite material.
RateFunction.m and RateFunction_FiniteBath.m set the rates for abundant and finite material, respectively.
